# @dreamboard-games/sdk-types

Public authoring and manifest types for Dreamboard game workspaces.

This package is part of the fixed-version `@dreamboard-games/*` SDK release
train. It contains shared TypeScript types consumed by the reducer SDK,
workspace codegen, UI packages, and generated game workspaces.

Typical imports:

```ts
import type { GameTopologyManifest } from "@dreamboard-games/sdk-types";
```

Use `@dreamboard-games/sdk` to inspect the coordinated package-set version.
