# @dreamboard-games/app-sdk

Reducer authoring SDK for Dreamboard game logic.

This package is part of the fixed-version `@dreamboard-games/*` SDK release
train. The public authoring surface is exposed through the reducer subpath.

Typical imports:

```ts
import { defineGame, definePhase } from "@dreamboard-games/app-sdk/reducer";
```

Use `@dreamboard-games/sdk` to inspect the coordinated package-set version.
