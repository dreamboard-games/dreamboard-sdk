# @dreamboard-games/workspace-codegen

Source generators for Dreamboard authored workspaces.

This package is part of the fixed-version `@dreamboard-games/*` SDK release
train. It generates manifest contracts, UI contract sources, typed table
helpers, and starter workspace files used by Dreamboard tooling.

Typical imports:

```ts
import { generateManifestContractSource } from "@dreamboard-games/workspace-codegen";
```

Use `@dreamboard-games/sdk` to inspect the coordinated package-set version.
