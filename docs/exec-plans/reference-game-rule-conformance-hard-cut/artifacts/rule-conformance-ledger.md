The approved local `rule.md` files are the authority for every row below. The
section/ordinal column counts the bullets exactly as they appear under each
file's `Acceptance obligations` heading; no rule IDs have been added to game
source. Reorderings or insertions in an authority file require this ledger to
be re-indexed.

## Status Key And Current Audit

- `absent`: no current source/test proof covers the complete obligation.
- `present-unverified`: related source or assertions exist, but the accepted
  reducer replay, perspective, player-count, or branch coverage is incomplete.
- `known-drift`: current source or tests materially disagree with the approved
  obligation.
- `executed-passing`: a non-vacuous current test executed the complete
  obligation successfully. This is not inferred from module import or
  typecheck success.

The current audit used the actual package test entrypoints plus source/test
inspection. `pnpm --dir examples/reference-games/hearts test`, Harbor Fair's
`pnpm test`, Last Light's `pnpm test`, and River Guild's `pnpm test` all exited 0. Only Hearts' 2-of-Clubs opening obligation is narrow enough for those
current assertions to constitute the complete rule proof. Lantern Market,
Sketchbook, and Mosaic Workshop currently report imported scenario modules as
passing without invoking their `then` callbacks. Stormtrail runs only two
parameter-schema tests. Cloudline's direct tests construct legacy public-state
helpers around a fixed roll table rather than replaying normal seeded reducer
setup. Harbor Fair's outcome tests use fixture-shaped deck orders, while Last
Light and River Guild execute reducers whose rules materially differ from the
approved briefs.
