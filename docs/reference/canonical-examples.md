# Canonical examples

The two supported examples are [Hearts](../examples/hearts.md) and
[Hex Network Trading](../examples/hex.md). Their game-local rule.md files define
mechanics and information boundaries. Typed scenarios prove those rules; UI
browser tests prove reachable presentation and interaction behavior.

Use Hearts for simultaneous passing, hidden hands and complete play. Use Hex for
manifest geometry, resource editing, independent exchanges and committed Bandits
steps. Directory discovery plus each schema-V5 reference-game.json is the game
inventory; removed historical examples are not supported API demonstrations.
